## 三、完整說明（上限 4000 字元）

```
「今天發生了一件事，我想遇到一個剛好懂的人。」

同頻 Today 不是傳統的交友軟體。這裡沒有無限滑照片，也不預設你是在找對象。
我們相信，人與人真正的連結，往往不是從外表開始，而是從「我今天也是這樣」開始。

■ 今天發生了什麼
每天寫下一件今天發生的事，可以是被主管唸了、可以是路上遇到一隻貓。
不必寫成日記，一段話就好。你也可以選擇自己現在想要什麼樣的回應——
想被安慰、想聽建議、只想被聽見，或只是想被轉移注意力。

■ 遇見同頻的人
系統會依照你的事件類型、情緒與期待的回應方式，找出今天和你有共鳴的人，
每天最多推薦五位，並且告訴你「為什麼是這個人」。
不是無限滑卡，因為我們希望每一次相遇都被認真對待。
雙方都表達想聊聊，才會開啟對話。

■ 樹洞：不想被配對的日子，也還有地方講話
匿名寫下心裡的話，其他人可以按「我懂」或留言陪你。
不必經營形象，不必擔心被認識的人看到。

■ 我們在意的安全
・不要求真名，不顯示精準位置
・發文前自動檢查個資與高風險內容
・聊天中若出現要聯絡方式、談錢、約見面的情況，會溫和提醒你留意
・可隨時封鎖、檢舉、退出對話，或刪除整個帳號

■ 適合誰
・下班後想說說話，但不想被當成在找對象的人
・對快速配對感到疲乏的人
・需要「被聽見」而不是「被建議」的人

慢一點沒關係。今天的事，慢慢說。
```

## 四、素材清單（規格）

| 素材 | 規格 | 狀態 |
|---|---|---|
| 應用程式圖示 | 512×512 PNG（32-bit，含 alpha） | ⚠️ **尚未製作**——目前 Android 專案用的是 Capacitor 預設圖示，上架前必須換掉 |
| 主題圖片 | 1024×500 PNG / JPG | ⚠️ 尚未製作 |
| 手機截圖 | 至少 2 張、建議 4–8 張；16:9 或 9:16，最短邊 ≥ 320px | ⚠️ 待實機截圖（建議：今日事件輸入、配對卡片、樹洞、聊天室） |
| 平板截圖 | 選填 | 免 |

> 截圖裡不要出現測試帳號的真實 email，也不要出現 `alice_n` / `bob3` 這類測試暱稱。

## 五、內容分級問卷（建議答案）

依照 App 實際內容作答：

| 問題 | 答案 | 說明 |
|---|---|---|
| 暴力 | 無 | |
| 性內容 | 無 | |
| 粗俗用語 | 無 | 使用者可能輸入，但有敏感詞過濾與檢舉機制 |
| 管制物品 | 無 | |
| 使用者可產生內容（UGC） | **是** | 樹洞貼文、留言、聊天訊息 |
| 使用者可互相溝通 | **是** | 一對一聊天 |
| 是否分享使用者位置 | **否** | 不收集精準位置 |
| 內容審核機制 | **有** | 發文自動檢查、檢舉、封鎖、隱藏 |

因為有 UGC 與陌生人互動，分級預期會落在 **12+ 或 17+**（以問卷結果為準）。
「目標對象與內容」建議選 **18 歲以上**——服務條款與註冊流程已限制未滿 18 歲不得使用。

## 六、資料安全表單（逐項答案）

### 是否收集或分享使用者資料
**是，有收集。**

| 資料類型 | 收集？ | 用途 | 必填？ | 分享給第三方？ |
|---|---|---|---|---|
| 電子郵件地址 | 是 | 帳號管理、密碼重設 | 必填 | 否 |
| 姓名 | 是（暱稱） | App 功能（顯示名稱） | 必填 | 否 |
| 使用者 ID | 是 | 帳號管理 | 必填 | 否 |
| 相片 | 是 | 個人檔案、貼文 | 選填 | 否 |
| 其他個人資訊 | 是（生日、性別、自我介紹、興趣） | App 功能（配對） | 選填 | 否 |
| 應用程式內訊息 | 是（聊天訊息） | App 功能 | 必填 | 否 |
| 使用者產生的內容 | 是（今日事件、樹洞貼文與留言） | App 功能 | 必填 | 否 |
| 位置 | **否** | 不收集 | | |
| 財務資訊 | **否** | 沒有金流 | | |
| 健康與健身 | **否** | | | |
| 聯絡人 / 通話記錄 / 簡訊 | **否** | | | |
| 應用程式活動記錄 | 是（當機與診斷日誌，不含貼文內容） | 分析與偵錯 | 系統自動 | 否 |

### 安全性做法
- ✅ 資料在傳輸過程中經過加密（全站 HTTPS）
- ✅ 使用者可以要求刪除資料 → 刪除網址：`https://dariowu1222.github.io/same-day-social-app/legal/account-deletion.html`
- ⚠️「是否遵循 Play 家庭政策」：本 App 非兒童導向，選否

> 補充說明：資料庫與檔案儲存使用 Supabase（資料處理者），登入可選用 Google／Facebook 驗證。
> 這些屬於**服務供應商代為處理**，不是把資料販售或分享給第三方作行銷用途。
